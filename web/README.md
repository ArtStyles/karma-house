# Fichas públicas

Proyecto Vercel con Root Directory `web`. `api/p.ts` sirve `/p/<id>` (reescrito en `vercel.json`) con la página pública de un anuncio aprobado y activo; el HTML se genera en el mismo archivo, sin imports, para que Vercel no tenga que resolver extensiones `.ts`; lo prueban `tests/public-listing.test.ts` desde la raíz del repo.

Variables de entorno del proyecto: `SUPABASE_URL` y `SUPABASE_ANON_KEY` (los mismos valores públicos de `.env.local`). La portada es una app de Vite + React + Tailwind CSS 4 con `motion` (antes Framer Motion) para animaciones: `index.html` lleva las metaetiquetas, `src/App.tsx` el contenido y `src/style.css` los estilos propios, que se cargan después de Tailwind. `public/` solo guarda imágenes y `robots.txt`, que Vite copia a `dist/`. Vercel ejecuta `npm run build` y publica `dist/` (fijado en `vercel.json`). En local: `npm install` y `npm run dev` dentro de `web/`. El alias `@/` apunta a `src/`, como esperan los componentes de 21st.dev y shadcn. `.vercelignore` excluye `tsconfig.json` para que la compilación de `api/p.ts` en Vercel no cambie; no instalar `typescript` en `web/` por el mismo motivo. La portada no consulta el catálogo ni muestra anuncios o cifras de actividad inventadas. Las fotografías y la conversación de ejemplo están identificadas como ilustrativas.

La portada ofrece KarmaHouse 0.1.16 para Android con el APK firmado alojado en la release pública `v0.1.16` de GitHub. El botón principal lleva al bloque de descarga; este enlaza el APK, las instrucciones y el archivo SHA-256 de la misma versión. Al publicar otra entrega, actualizar conjuntamente estos enlaces, el tamaño, la versión y las preguntas sobre disponibilidad y comprobación. No publicar el enlace hasta haber comprobado una descarga anónima completa y su hash. La página no incorpora aún el observatorio inmobiliario propuesto.

El rediseño de octubre de 2026 toma como referencias la organización por intención de Idealista, Rightmove y Zillow, manteniendo una portada de presentación porque el catálogo se usa en la app. Conserva las rutas `/p/<id>` y los enlaces legales.

La propuesta visual posterior (`src/App.tsx`, `src/ui.tsx`, tokens en `src/index.css`) parte de la arquitectura habanera: el mediopunto (vitral de medio punto) corona la foto como una puerta, la losa hidráulica aparece como textura y cenefa, y la paleta sale de la foto de Vedado (cal, persiana, terracota, sol) más el azul de la app. Titulares en Calistoga (41 KB, servida desde el propio sitio); el resto usa la fuente del sistema. Las animaciones usan `motion` con `LazyMotion`/`domAnimation` y `MotionConfig reducedMotion="user"`; el verbo del titular recorre las cuatro operaciones una sola vez (menos de 5 s) y la lista de provincias tiene botón de pausa. El teléfono reproduce la pestaña Explorar de la app con foto ilustrativa y barras en lugar de un anuncio inventado. Las fotos se sirven en AVIF con JPG de respaldo. Las provincias copian `PROVINCES` de `src/domain/listingOptions.ts`; si cambia allí, actualizar `src/ui.tsx`.

La navegación móvil y las preguntas usan `<details>` nativo; `MobileMenu` solo cierra el menú al elegir una sección o pulsar Escape. La portada necesita JavaScript para mostrarse (unos 113 KB comprimidos); antes de publicarla conviene prerenderizar el HTML en el build.
